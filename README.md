# Python Labs

Python implementations covering algorithms, data processing, object-oriented design, multiprocessing, and asynchronous I/O.

## Projects

### `algorithms-and-data-structures/`

A collection of independent algorithmic and data-processing exercises. Topics include depth-first search, connected components, dynamic programming, structured data processing, and numeric parsing.

### `concurrent-applications/`

Two larger applications and associated exercises:

- **Exam simulator:** object-oriented simulation with examiner/student models, randomized behavior, and multiprocessing.
- **Asynchronous image downloader:** concurrent HTTP downloads using Python asynchronous programming and streaming responses.

## Technology

Python 3, `multiprocessing`, `asyncio`, `httpx`, `anyio`, and `PrettyTable` (where used by the corresponding project).
